Game Theory

Sponsor: Google Quantum AI
Project: Quantum Parity Processing Unit
Team: Anish Jaiswal, Brian Hu, William Lee, Alexander Espinoza, Ali Shahid



Mentor(s): Adam Zalcman, Justin Ledford
Project Overview: This project focuses on designing and implementing a domain-specific FPGA processor and a custom ISA toolchain that computes parity detection events in real time from a 1,000-qubit quantum processor. By keeping pace with a 400 ns error correction cycle, the system enables real-time syndrome processing for fault-tolerant quantum computing and lattice surgery operations.

MB-RDC

Sponsor: Google Quantum AI
Project: Hardware Acceleration for Quantum Error Correction
Team: Cheng Xi, Ryan Hung, Nathan Ngo, Luis Mendoza, Milad Haghighi



Mentor(s): Adam Zalcman, Justin Ledford
Project Overview: Extend the Micro Blossom decoder with two capabilities: decoding syndrome produced by non-trivial quantum algorithms realized using lattice surgery (as opposed to syndrome produced by quantum memory), and handling syndrome produced by realistic superconducting qubit quantum processors (open sets and possibly proprietary experimental data) where some qubits and couplers may be broken.

Team Mysten

Sponsor: Mysten Labs
Project: Agentic Digital Asset Tool
Team: Abhijeet Dutta, Daniel Chang, Jovia Low, Kalyan Rajavaram, Samprita Chakraborty



Mentor(s): Alberto Sonnino, Deepak Maram
Project Overview: This project develops an AI-powered, security-focused wallet for the Sui blockchain which will simplify the experience of managing digital assets through plain English commands and a secure, human-involved approval system. Ultimately, it will deliver an entire framework consisting of a working AI wallet that uses an MCP server, isolated signer daemon, and deterministic policy engine, a deployed Move package, and a security evaluation with a written report on the overall design, threat model, and evaluation.

Q*

Sponsor: Nutanix
Project: EVO: Self-Evolving OSS Project Manager Agent
Team: Clement Boiteux, Hanson Hu, Mihir Srivastava, Shanqin Chen, Timothy Nguyen



Mentor(s): Srinath GS, Kostadis Roussos
Project Overview: Nutanix is developing an agent that can serve as a project manager to organize tasks and ensure quality of work. The agent will proactively exercise various aspects of the software development life cycle, such as prioritizing and assigning project tasks, judging code correctness and deployment readiness, and assisting human engineers with root cause analysis for failures. This agent enables human developers to drive software projects to completion in a timely manner without worrying about smaller details that could introduce friction in the development process.

4Orbit

Sponsor: SpaceComputer
Project: Agentic KMS: Policy-Controlled Secrets and Cryptographic Access for AI Agents
Team: Binghao Cui, Jason Zhao, Matt Blanke, Lauren Cho, Derek Kirschbaum



Mentor(s): Pedro Sousa, Filip Rezabek, Daniel Turin, Amir Yahalom
Project Overview: Our project will build a policy-controlled authorization and credential management system for AI agents using SpaceComputer’s KMS and Orbitport. The system will allow agents to authenticate, receive narrowly scoped permissions for secrets and cryptographic operations, and perform real workflows while enforcing access through Cedar-based policies. The final system will demonstrate multiple agents with different roles and capabilities, along with auditing and visibility into authorization decisions.
